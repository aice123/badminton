# 火柴人羽毛球 · 高难度版（单文件版）

纯前端的 HTML5 小游戏：Canvas + 原生 JS，**没有任何外部依赖、不联网也能玩**。
想玩或想发给别人，只要一个文件：`badminton-updated.html`（双击、或拖进浏览器）。手机上也能玩。

## 三种模式

| 模式 | 说明 |
| --- | --- |
| 单人 · 人机 | 和电脑对打，四档难度（简单 / 普通 / 困难 / 地狱） |
| 双人 · 同屏 | 两人一台设备，左右各一套操作 |
| 观战 · 互打 | 两边都是电脑，可以看两个 AI 互殴 |

赛制：**三局两胜、每局 15 分**（14 平后须净胜 2 分，21 分封顶）。每局每分发球前会提示局点 / 赛点。

## 操作

### 单人（键盘）

| 按键 | 作用 |
| --- | --- |
| `A` / `D`（或 ← →） | 左右移动 |
| `W` / ↑ | 起跳（跳起来接球时，较低的点也能扣杀） |
| `空格` / `J` | 挥拍、发球（触球点够高时自动扣杀） |
| `S` / ↓ / `L` | **直接**挥拍吊球；发球时按它 = 发低平短球 |
| `Shift` / `K` | **直接**挥拍打高远球 |
| `H` / `M` / `P` / `R` | 落点提示 / 音效 / 暂停 / 重开 |

### 双人（右侧玩家用小键盘）

| | 玩家 1（青） | 玩家 2（橙） |
| --- | --- | --- |
| 移动 | `A` / `D` | **小键盘 4 / 6**（或 ← →） |
| 起跳 | `W` | **小键盘 8**（或 ↑） |
| 挥拍 | `空格` / `J` | **小键盘 0** |
| 吊球 | `S` / `L` | **小键盘 5** |
| 高远球 | `Shift` / `K` | **回车 Enter** |

小键盘按 `e.code` 识别，**NumLock 开或关都能用**。

### 手机 / 平板（触屏）

- 左下角虚拟摇杆：左右推 = 移动，往上推过半 = 起跳
- 右下角动作键：`吊球`、`高远`、`挥拍`
- 右上角小键：`🔊 音效`、`⏸ 暂停`、`☰ 返回菜单`
- 双人模式下左右各一套（镜像对称）；观战模式下操作键全部隐藏
- 竖屏会提示"请横屏游玩 / 请使用浏览器打开"

## 规则（按真羽毛球来）

- **发球区**：落点必须在前发球线（距网 129px ≈ 1.98m）与端线之间，否则判发球违例
- **站位空气墙**：发球时发球方不能越过发球线
- **禁止过网击球**：触球点必须在击球方自己半场（留 6px 宽容度）
- **不许连击**：同一方在一个回合内不能连续击球两次；**同一次挥拍也只算一次击球**——
  第一下打出去之后，球被对手打回来、正好又碰到还在回正的拍子，不算击球
- **出界 / 下网**：落点在场地外判"出界"，落在击球方自己半场判"下网"

## 电脑是怎么打的

它不是"跟着球跑"的脚本，而是一台会算弹道的规则机器人，每帧（120Hz）做这几件事：

1. **精确预测**：复制球的当前状态，用**和玩家完全相同的物理积分器**往前推，得到带时间戳的轨迹。
2. **提前站位**：球在对面时站防守位；预判落点很靠网会提前上前；快球会"蹬地"加速。
3. **出手前先在脑子里把这一挥重演一遍**：球按同一套物理逐帧走、拍子按同一个挥拍动作和有效窗口走、
   用同一套判定圈（拍尖 50px / 身体 86px）比对，并且留 14px 余量。**能碰到才挥** ——
   空挥会被收拍冷却锁死 0.4 秒，那段时间球会一路掉到腰下，等于白送一分。
4. **选球路**：按触球高度和你的站位选落点（你退后场就吊网前、你压网前就打你后场），
   再用二分法反解出球初速度，让球精确落在那个点上。
5. **接后场高远球**：约 30% 概率改下压（球够高扣杀、否则劈吊 / 平抽），其余回高远压向你底线。

### 四档难度（只调"能力属性"，规则完全一样）

| 难度 | 反应 | 移速 | 站位误差 | 瞄准误差 | 扣杀倾向 | 力量 | 弧线压平 | 随机换球 | 落点抖动 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 简单 | 0.30s | 285 | ±72px | ±105px | 15% | ×0.72 | 1.00 | 30% | ±80px |
| 普通 | 0.17s | 362 | ±39px | ±52px | 47% | ×0.90 | 0.92 | 28% | ±60px |
| 困难 | 0.14s | 392 | ±40px | ±50px | 52% | ×0.90 | 0.80 | 34% | ±70px |
| 地狱 | **0s** | 500 | **±0px** | **±0px** | **100%** | ×1.30 | 0.42 | 40% | ±85px |

（玩家参考：移速 400；扣杀速度每次随机 230~565 km/h；1m ≈ 65px）

## 改完怎么重新生成、怎么验证

```bash
cd badminton
node patch_desktop.js            # 生成 badminton-updated.html（必须全绿：任何一处补丁没匹配会报错退出）
node test_updated_smoke.js       # 冒烟：玩家端没被动、三种模式、伪 DOM 渲染 600 帧
node test_updated_clear.js       # 电脑接后场高远球的击球点高度 / 回球种类 / 是否起跳
node test_updated_clearrally.js  # 互拉高远模拟：会不会漏球、回高远与下压的比例
node test_updated_slowrecv.js    # 受控实验：慢高远打到后场/中场/贴网能不能接
node test_updated_game.js        # 整局体检：胜负、空挥率、起跳次数、球种分布
node test_updated_miss.js        # 逐帧追"漏接"，按落点深度分层统计
node test_updated_doublehit.js   # 一次挥拍只能击中一次（回正时再碰到球不算）
```

> 改完一定要重新 `node patch_desktop.js`，否则网页加载的还是旧文件（刷新一下页面即可看到新版）。
