# 火柴人羽毛球 · 高难度版

一个纯前端的火柴人羽毛球小游戏：**单文件 HTML，双击就能玩，不用装任何东西，断网也能玩**，手机上也能玩。

![截图](screenshot.png)

## 玩法

- 三种模式：**单人打电脑**（四档难度）、**双人同屏**、**观战**（两个 AI 互打）
- 赛制：三局两胜，每局 15 分（14 平后要净胜 2 分，21 分封顶）
- 电脑不是"跟着球跑"的脚本：它用和玩家完全相同的物理去预测你的球路、提前站位，
  出手前还会在脑子里把这一挥按真实判定重演一遍——能碰到才挥。所以它很少空挥，也不容易被慢球骗到。

## 操作

单人（键盘）：

| 按键 | 作用 |
| --- | --- |
| `A` / `D` | 左右移动 |
| `W` | 起跳（跳起来接球时，较低的点也能扣杀） |
| `空格` / `J` | 挥拍、发球 |
| `S` | 直接吊球（发球时按它 = 发低平短球） |
| `Shift` / `K` | 直接打高远球 |
| `H` / `M` / `P` / `R` | 落点提示 / 音效 / 暂停 / 重开 |

双人：右侧玩家用小键盘 `4` / `6` 移动、`8` 起跳、`0` 挥拍、`5` 吊球、`Enter` 高远球（NumLock 开或关都行）。

手机：左下角虚拟摇杆（往上推过半 = 起跳），右下角三个动作键（吊球 / 高远 / 挥拍），右上角是音效、暂停、返回菜单。

## 规则

按真羽毛球来：发球落点必须在前发球线与端线之间，否则判发球违例；发球时不能越过发球线；
不能在对方半场击球；同一方不能连击（同一次挥拍也只算一下）；落在场外判"出界"，落在自己半场判"下网"。
每局每分发球前会提示局点 / 赛点。

四档难度只改电脑的能力（反应、移速、站位与瞄准误差、力量），规则完全一样。
